#+title: jjosh
#+subtitle: 在一起开发，向各自的仓库发布
#+options: toc:nil num:nil

jjosh 扩展 [[file:jj/][Jujutsu]]，让一个本地仓库里的多个项目与各自的 Git 仓库交换历史；仓库布局的转换由 [[file:josh/][Josh]] 完成。
你可以在同一个 change 中修改应用和依赖，一起构建、测试，再只把依赖的修改送回它的上游或 fork。
日常仍使用 jj 的修改图、书签、冲突处理和 operation history。

项目指定本地哪部分内容独立交付；项目的 remote 指定外部仓库及其布局。
每个项目和仓库根各有自己的 remote 名字，因此都可以叫 =origin=。

* 安装与准备

需要 Rust 1.95+、Git，以及本仓库中的 =jj/=、=josh/=、=gitoxide/= 本地源码。
在仓库根目录构建并加入 PATH：

#+begin_src sh
cargo build --locked --release -p jjosh-cli
export PATH="$PWD/target/release:$PATH"
#+end_src

历史转换目前要求 SHA-1 Git backend。下面新建非 colocated 仓库，便于以后调整检出布局。
已有 jjosh 仓库升级前，先读[[file:docs/workflows.org][使用指南]]中的迁移与备份说明；不要让不兼容的旧程序继续写入。
即使尚无子项目，通过 jjosh 管理根 remote 也可能启用带连接身份的 v3 存储；此后不能让旧版或上游原版 jj 写入该存储。

* 最短工作流：带入、修改、发布

假设 parser 的 Git 仓库有 =main= 分支，你有创建 =topic= 分支的权限。
将 =/path/to/parser.git= 换成真实本地路径或 Git URL；=mono= 是尚未存在的目标目录。

#+begin_src sh
jjosh git init --no-colocate --object-hash sha1 mono
cd mono
jjosh describe -m 'Start monorepo'
jjosh project add parser --path libs/parser
jjosh git remote add origin /path/to/parser.git --project parser --whole
jjosh git fetch --project parser --branch main
jjosh new @ main#parser@origin
#+end_src

现在编辑 =libs/parser/= 中的代码，也可以同时修改应用。
=--whole= 表示外部仓库根目录对应本地整个 parser 项目；fetch 带入历史，new 将它与本地工作合在一起。

#+begin_src sh
jjosh status
jjosh diff
jjosh describe -m 'Extend parser and update its callers'
jjosh bookmark create topic#parser -r @
jjosh git push --bookmark topic#parser --dry-run
#+end_src

完成项目需要的构建、测试并解决冲突，检查计划中的地址、目录和分支，然后发布：

#+begin_src sh
jjosh git push --bookmark topic#parser
#+end_src

远端收到 =topic= 分支，内容来自 =libs/parser/=，并放在远端根目录。
同一提交中的应用修改不会被这个项目的发布带走。
=#parser= 是稳定的项目引用 label；=main#parser@origin= 读取 parser 的 origin 记录，=topic#parser= 则选定本地交付版本。
书签指向完整提交，并不是一个只含 parser 文件的提交。

* 开发入口

CLI 入口与工作流测试在 [[file:crates/jjosh-cli/][crates/jjosh-cli/]]。
=jj/=、=josh/=、=gitoxide/= 保留各自的 Cargo workspace；根目录的 =.cargo/config.toml= 把依赖指向这些本地源码。

#+begin_src sh
cargo test --locked -p jjosh-cli
cargo clippy --locked -p jjosh-cli --all-targets
#+end_src
